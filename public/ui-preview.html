HRNAL — one app, two interfaces

After login the app reads the account's role and opens the matching experience. Screenshots below are from the iOS simulator with demo data.

Student — existing app, unchanged

Exactly the interface students already use; only the app name changed to HRNAL.

Teacher — new, from the reference design

Shown only when a teacher account signs in. Bottom navigation: Home · Lessons · Check In (raised) · Attendance · Profile.

Who sees what

Student loginStudent app (blue) — home, check-in, reports, attendance, notifications, profile
Teacher loginTeacher app (this new UI) — lessons, attendance, salary profile, green check-in
Future rolesParent / Admin plug into the same role switch without touching existing screens
